⌨️

CLI Boot

The system wakes up in a terminal with a colorful prompt. Launch the desktop whenever you need it: startx.

🌟

Boot Animation

A pink star pulses during boot (Plymouth), and after logging in, it grows line by line right in the terminal.

📋

LuminaFetch

A custom neofetch equivalent with an ASCII star and full info: CPU, GPU, RAM, disk, IP, boot mode.

💿

CLI Installer

luminal-install in a pink theme. Copies the system from the live image, requiring no internet connection.

🪟

Dual-boot

Install alongside Windows or another Linux. GRUB detects other operating systems automatically (os-prober).

🖥️

Download ISO image

Download the ready-to-use system image directly from Google Drive, then write it to a USB flash drive.

Download ISO (Google Drive)

After downloading the ISO file, use the following terminal command to write it to your USB drive:

sudo dd if=luminal-amd64.hybrid.iso of=/dev/sdX bs=4M status=progress conv=fsync

Replace /dev/sdX with your USB drive (the whole device, without partition numbers).

Installation in four steps

From downloading the image to a working system in just a few minutes.

  1. Download ISO
    Get the ISO file directly from Google Drive.
  2. Write to USB
    Save the image to a USB flash drive (4 GB+) via dd, Rufus, or Etcher.
  3. Boot from USB
    Disable Secure Boot, select the USB drive from your boot menu, and watch the star.
  4. Run Installer
    Type sudo luminal-install, choose your disk, mode (entire disk or dual-boot), and desktop.

Build LuminaL yourself

Alternatively, you can build the image yourself using a single script on Debian or Ubuntu (approx. 15 GB space required, 20–40 minutes).

FAQ


Do I need an internet connection for installation?

No, if you choose CLI, XFCE, or i3. Other desktops download packages from the official Debian repositories.

Can the installer keep my Windows partition?

Yes, by using the dual-boot mode.

Does it work with Secure Boot?

No. The bootloader is unsigned, so Secure Boot must be disabled in your UEFI/BIOS settings.

Is this a production-ready product?

It is a hobby project. Please test it first in QEMU or on a spare drive before installing it on your main computer.
